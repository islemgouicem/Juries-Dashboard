# ⚖️ Juries Dashboard

A real-time evaluation system designed for hackathons, datathons, and ideathons, enabling structured team assessment, scoring, and ranking.

🌐 Live System: https://mobai-juries.netlify.app/

Built for structured jury-based evaluation workflows used in competitive events.

---

## ⚡ Overview

The MobAI Juries Dashboard is a digital platform that allows juries to:

- Evaluate teams using predefined criteria  
- Assign structured scores per category  
- Automatically calculate total points  
- Generate live rankings  
- Ensure transparent and consistent judging  

It replaces manual scoring sheets with a **real-time, data-driven evaluation system**.

---

## 🧠 Core Idea

In competitive events, judging often suffers from:

- Inconsistent scoring  
- Manual calculation errors  
- Delayed results  
- Lack of transparency  

This system solves that by introducing:

> 🧾 Structured scoring + ⚡ real-time updates + 📊 automatic ranking

## 🚀 Key Features

### 👨‍⚖️ Jury System
- Individual jury accounts
- Secure authentication via Supabase
- Personalized evaluation dashboard

### 📊 Evaluation Engine
- Multi-criteria scoring system
- Weighted or structured evaluation (configurable)
- Instant score aggregation

### 🏆 Live Ranking
- Automatic team ranking updates
- Real-time leaderboard synchronization

### 🧑‍💻 Admin Panel
- Manage teams and jury flow
- Control evaluation order
- Monitor scoring progress
- View final rankings and statistics

### 🔄 Real-time Sync
- Instant updates using Supabase real-time database
- No manual refresh needed

## 🛠️ Tech Stack

- Frontend: React / Next.js *(adjust if needed)*  
- Backend: Supabase  
- Database: PostgreSQL (via Supabase)  
- Auth: Supabase Authentication  
- Real-time: Supabase Realtime  
- Deployment: Netlify  

---

## 🧩 System Architecture

1. Admin sets up teams and jury accounts  
2. Juries log in securely  
3. Each jury evaluates teams using criteria  
4. Scores are stored in Supabase database  
5. System aggregates scores in real-time  
6. Rankings update instantly
